# Генератор заданий: Машинное представление вещественных чисел

Программа на языке C для автоматической генерации индивидуальных учебных заданий по теме "Машинное представление вещественных чисел в формате IEEE 754".

##  Описание

Приложение создаёт варианты заданий для студентов, где требуется:
1. Перевести вещественное число в машинное представление (32 или 64 бита)
2. Восстановить число из битового представления
3. Вычислить ошибку округления

Программа автоматически генерирует как **задания**, так и **решения** с подробными таблицами в формате Markdown.

##  Возможности

-  Генерация произвольного количества вариантов
-  Настраиваемый диапазон чисел и точность
-  Автоматическое вычисление ошибок округления
-  Вывод в читаемом формате Markdown
-  Раздельные каталоги для заданий и решений

##  Структура проекта

После запуска программа создаёт:
```
.
├── info.txt              # Конфигурация (параметры генерации)
├── data.txt              # Сгенерированные числа
├── Task/                 # Каталог с заданиями
│   ├── variant_1.md
│   ├── variant_2.md
│   └── ...
└── Solve/                # Каталог с решениями
    ├── variant_1.md
    ├── variant_2.md
    └── ...
```



##  Использование

Программа запрашивает следующие параметры:

1. **Количество вариантов** (n) — сколько студентов
2. **Количество заданий** (k) — заданий на одного студента
3. **Разрядность** — 32, 64 или 128 бит (128 автоматически заменяется на 64)
4. **Диапазон чисел** — от `a` до `b`
5. **Знаков после запятой** (p) — точность вывода (0-10)

### Пример взаимодействия:
```
Введите количество вариантов: 3
Введите количество заданий для одного студента: 5
Введите разрядность вещественного числа (32, 64, 128): 32
Введите диапазон представления вещественного числа (a b): 0 100
Введите количество знаков после запятой: 2
```

##  Формат выходных файлов

### Задание (`Task/variant_N.md`):
```markdown
# Вариант 1

| № | Вещественное число | Формат |
|---|-------------------|--------|
| 1 | 10.18 | 32 бит |
| 2 | 45.67 | 32 бит |
```

### Решение (`Solve/variant_N.md`):
```markdown
# Решение Варианта 1

| № | Исходное число | Машинное представление | Восстановленное | Ошибка |
|---|---------------|----------------------|----------------|--------|
| 1 | 10.18 | 0100 0001 0010 0010 1100 1110 1001 0000  | 10.18 | 2.979e-07 |
| 2 | 45.67 | 0100 0010 0011 0110 1010 1100 0001 0000  | 45.67 | 5.722e-06 |
```
